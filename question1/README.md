Student Marks Management System
Problem Statement
Develop a Python program to manage student marks, calculate total marks, average marks, grade and pass/fail result.

Approach / Logic Used
Store student details using a list of dictionaries.
Calculate total and average marks.
Use a function to assign grades.
Use conditions to determine PASS or FAIL.
Find the highest scoring student.
Use list comprehension to find students scoring above 75.
How to Run the Program
python main.py

Sample Input
Rahul - Python=85 SQL=75 AI=80

Anjali - Python=60 SQL=65 AI=70

Priya - Python=90 SQL=85 AI=80

John - Python=30 SQL=35 AI=40

Sample Output
===== Student Result =====

Student ID: 101

Name: Rahul

Total: 240

Average: 80.0

Grade: A

Result: PASS

Highest Scoring Student: Priya

Students above 75: Rahul, Priya
